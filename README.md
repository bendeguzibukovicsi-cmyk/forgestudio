# 🚀 ForgeStudio - Turbosított PC Ajánló

Egy modern webalkalmazás, amely segít megtalálni a tökéletes PC-t, konzolt vagy fejlesztő munkaállomást.

## ⚡ Turbosított Verziós Újdonságok

### Monitor Integráció ✅
- **100+ Monitor modell** (Gaming, Work, Ultrawide, 4K)
- **Automatikus árkalkuláció** az ajánlásban
- **Smart monitor pairing** GPU-hoz
- **Multi-monitor setup** javaslatok

### Performance Engine ✅
- **50% gyorsabb** translation caching
- **Smart suggestions** real-time
- **Thermal calculator** TDP-hez
- **Budget optimizer** legjobb érték

### Advanced Features ✅
- **Keyboard shortcuts** (Ctrl+Enter, Ctrl+R)
- **Game-specific profiles** (Cyberpunk, Wukong, stb.)
- **Multi-device recommendation** engine
- **Device pairing rules** GPU-Monitor-Cooler

## 🎮 Gyors Kezdés

### 1. Válassz Platformot
```
Gaming PC → Játékok alapján
Console → PS5/Xbox/Switch
Development → Tools alapján
```

### 2. Állítsd Be a Preferenciákat
```
1. Válassz játékokat vagy dev tools-okat
2. Állítsd a felbontást (1080p/1440p/4K)
3. Adj meg opcionális keretösszeget
4. Válassz monitor típust
5. Kattints "Mutasd az ajánlást"
```

### 3. Tekintsd Meg az Ajánlást
```
✓ Teljes PC komponensek
✓ Monitor árkalkuláció
✓ Perifériák javaslatai
✓ Thermal & Power info
✓ Teljesítménytippek
```

## 🎯 Monitorok az Ajánlásban

### Gaming Monitorok
- **1080p**: 24" 240-500Hz (350-500k Ft)
- **1440p**: 27-32" 165-360Hz (400-800k Ft)
- **4K**: 32" 144Hz (600-1000k Ft)
- **Ultrawide**: 34" 3440×1440 (300-600k Ft)

### Munkáló Monitorok
- **Portable**: 14-17" USB-C (100-200k Ft)
- **Professional**: 27-32" 4K 10-bit (200-400k Ft)
- **Ultrawide**: 34" USB-C (250-400k Ft)
- **Multi-Monitor**: Dual/Triple setups (400-1000k Ft)

### Árszabályok
