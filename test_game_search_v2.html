💡 Fuzzy Search Algoritmusa:

A fuzzy search az egyes karaktereket vizsgálja meg és pontozza őket:
• Pontos match (a teljes szövegben szerepel) = 500 pont
• Szó kezdete (eleje egyezik) = 1000 pont
• Alias match (rövid név) = 250 pont
• Fuzzy match (nem folyamatos, de ok) = 1-N pont

Ezek alapján kerülnek sorrendbe a játékok.
